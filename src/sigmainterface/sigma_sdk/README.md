# SigmaSDK 仿真控制 Demo 说明文档

## 一、项目简介
本项目是基于 **UDP 协议** 开发的仿真平台 SDK 示例程序，封装网络通信与仿真协议编解码，实现向仿真服务端下发控制指令、后台异步接收解析仿真推送消息，可用于无人仿真场景模型生成、运动控制、参数交互等业务。

## 二、核心功能
1. 发起仿真数据请求
2. 实体飞行器/模型运动指令控制
3. 模型自定义标签配置
4. 仿真模型动态生成与姿态、位置、缩放配置
5. 独立后台线程，持续接收并解析仿真下行消息
6. 通用 UDP 通信封装，支持单发、指定IP端口发送、广播适配

## 三、工程目录结构
├── test.cpp                // 工程单测程序，测试消息回调和发送功能

├── sigmaSDK.h              // SDK 对外接口头文件

├── sigmaSDK.cpp            // SDK 接口实现

├── sigmaAssist.h         // 辅助函数

├── dxfd_protocol/          // 仿真协议结构体与编解码依赖头文件

└── README.md               // 项目说明文档
## 四、运行环境依赖
1、运行环境：Linux
2、编译标准：C++11 及以上
3、依赖库：pthread 多线程、Linux Socket 网络接口
4、外部依赖：dxfd_protocol 仿真协议定义文件

## 五、新分支说明
新分支主要用于机车学院项目的开发使用，作为独立sdk静态库链接，或编入interface库，不再作为独立程序运行。
